# Hers Cottons — agent notes

A static landing page for a women's ethnic-wear shop in Aligarh, trading since
1980. Read this before changing anything.

## Corrections to earlier versions of this file

The previous revision described a React + Vite + Spline app talking to the
**Instagram Basic Display API**. None of that was ever built, and the API was
permanently shut down by Meta on **4 December 2024**. It also warned that
`/photos` contained HEIC files needing conversion — they were JPEGs with a
`.HEIC` extension all along. Do not reinstate any of it.

## What this actually is

Plain HTML, CSS and ES modules. **No framework, no bundler, no build step.**
Open `index.html` and it works.

```
index.html              the whole page
assets/css/main.css     design system and layout
assets/js/main.js       page behaviour, feed loading, scroll choreography
assets/js/gl.js         hand-written WebGL2: hero cloth shader + weave gallery
assets/img/             generated, responsive WebP (do not edit by hand)
assets/instagram/       generated by the daily Action (do not edit by hand)
photos/                 source photographs — the masters
scripts/                generators and verifiers
docs/INSTAGRAM_SETUP.md one-time setup for the live feed
```

## Rules

**No runtime dependencies.** There is no Three.js, no GSAP, no jQuery. Those
were removed deliberately: they cost ~670KB over the wire and the customers here
are on mid-range Android over 4G. If an effect seems to need a library, write
the shader. `assets/js/gl.js` is a few KB and does more than the old Three.js
scene did.

**Never invent shop facts.** Prices, fabric names, product counts, awards,
history — if it is not already on the page or supplied by the owner, do not
write it. Fabric captions in the gallery describe visible colour and pattern
only, because claiming a specific technique on a specific bolt would be a guess.

**Everything degrades.** The WebGL is decoration layered on complete HTML. It is
skipped entirely on `prefers-reduced-motion`, on Save-Data, on 2G/3G, on devices
reporting under 4 cores or under 4GB RAM. Never make content depend on it.

**Regenerate, do not hand-edit.** `assets/img/` and `assets/instagram/` are
build output.

## Scripts

```bash
npm run images          # photos/ -> responsive WebP + crops + manifest
npm run contact-sheet   # labelled grid of the whole library, for art direction
npm run instagram       # pull the live feed (needs INSTAGRAM_ACCESS_TOKEN)
npm run serve           # local preview on :4173
node scripts/check-links.mjs      # every asset reference resolves
node scripts/check-contrast.mjs   # every text pair passes WCAG AA
```

Run both checkers before committing. They exist because the original site
shipped three broken images and a gold that was 2.4:1 on cream.

## Gotchas that cost real time

**Grid alignment applies to absolutely positioned children.** `.hero` uses
`place-items: center`, which made `.hero__stage` shrink-to-fit to 1px wide. Both
it and `.hero::after` need explicit `place-self: stretch`. `.hero__content`
needs `width: 100%` for the same reason, or it overflows narrow screens and its
buttons never wrap.

**`sharp.metadata()` reports pre-rotation dimensions.** After `.rotate()`
applies EXIF orientation, width and height are swapped for orientations 5–8.
Using the raw metadata for crop maths produces `bad extract area`.

**The green astroturf cannot be chroma-keyed out.** It was tried. No threshold
separates the background grass from green *fabric*, so it discoloured the
merchandise. The crop search in `optimize-images.mjs` is the accepted answer.
The real fix is better photography.

**Instagram tokens expire in 60 days with no grace period.** The daily Action
refreshes them. If it is disabled for 60 days the feed dies and needs manual
re-authorisation.

## Known gaps

- No product photography on models, and no interior shots. The library is
  flat-lays on artificial grass plus one shopfront. This is the single biggest
  ceiling on how good the site can look.
- Gallery captions describe appearance, not product. Replace with real names
  when the owner supplies them.
- Domain is `herscottons.pages.dev`. Update the canonical URL, Open Graph tags,
  `sitemap.xml` and `robots.txt` together if a custom domain is bought.
